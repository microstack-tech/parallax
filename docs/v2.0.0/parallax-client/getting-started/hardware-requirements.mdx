The hardware requirements for running a Parallax node depend upon the node configuration and can change over time as the network grows. Parallax nodes can be run on low power, resource-constrained devices such as Raspberry Pi's. However, many users will choose to run nodes on laptop or desktop computers.

Parallax uses 10-minute block times and the chain is currently small, so requirements are modest.

## CPU

A single-core CPU is sufficient to run a node. A dual-core or better is recommended, especially for mining.

## Memory

It is recommended to use at least 2 GB RAM. 4 GB or more is recommended for mining or running additional services.

## Disk space

At the time of writing, the Parallax chain is in its early stages with minimal state. A 50 GB SSD is sufficient for a full node. We recommend 100 GB SSD to allow room for growth and DAG file storage used by the XHash mining algorithm.

Archive nodes that retain all historical state back to genesis require additional space. A fast SSD is recommended over HDD for read/write performance during sync.

## Bandwidth

A stable internet connection with at least 1 Mbps is sufficient to run a node. 10 Mbps or more is recommended for faster initial sync and reliable peer connectivity. It is better to use an ISP that does not have a capped data allowance.
